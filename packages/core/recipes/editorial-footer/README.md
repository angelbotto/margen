```html
{{EXAMPLE}}
```

**Uso:** cierra con la identidad y los enlaces de quien escribe. Las dos columnas se apilan en móvil; las descripciones de enlaces se difuminan solo con puntero fino y se revelan también con foco de teclado. La atribución a Margen queda separada.

El generador ofrece la misma pieza mediante `footer: {author, note, links: [{label, href, detail}], platform}`. No añadas un segundo pie manual cuando uses esa opción. Se aceptan HTTPS sin credenciales y correo `mailto:`. No se inventan redes, licencias, estadísticas ni autoría: los enlaces de esta muestra corresponden al proyecto, no a una persona ficticia. El pie sigue al contenido y conserva la identidad del documento.
