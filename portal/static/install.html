Conectar mi cuenta →

Instalar el skill no inicia sesión. Puedes crear HTML sin cuenta; para publicarlo, conecta una vez este usuario del equipo a tu cuenta de Margen.

  1. Entra con tu correo

    Usa tu propia cuenta de Google o el código enviado a tu correo.

  2. Crea tu conexión

    En «Conectar un agente», ponle un nombre, por ejemplo «Mi portátil», y copia tu token personal.

  3. Conecta en la terminal

    El comando de abajo pide tu correo y el token de forma oculta. Comprueba que ambos pertenecen a tu cuenta.


    

    
Los agentes de este usuario del equipo comparten la conexión. Cada compañero conecta la suya. No pegues tokens en el chat ni los incluyas en un artefacto.

  

  

    
Antes de empezar

    
¿Necesito una cuenta para crear?
No. Generar y leer HTML funciona sin cuenta. Conectar tu cuenta permite guardar versiones en el portal, compartir y reunir comentarios. La cuenta de tu agente y la cuenta de Margen son independientes.

    
¿Cómo actualizo después?
Ejecuta margen update o vuelve a usar el instalador. Las actualizaciones recuerdan los agentes seleccionados. Si agregas otro, selecciona todos los que quieras mantener actualizados.

    
¿Uso Windows o WSL?
Elige Windows si tu agente corre en PowerShell. Si corre dentro de WSL, marca esa opción y ejecuta el comando en la terminal de Linux. Son instalaciones separadas; usa el entorno donde trabaja tu agente.

    
¿Y si trabajo desde ChatGPT u otro entorno?
La instalación local no instala extensiones en una web. Si tu entorno permite importar skills, puedes usar el paquete portable; consulta sus instrucciones de importación.
